# Stock Status Evaluation of the Tank Goby (Glossogobius giuris) in Kaptai Lake, Bangladesh

## **Project Overview**
This repository contains the research data and analytical scripts for the stock assessment of the Tank Goby (*Glossogobius giuris*). The study focuses on evaluating population dynamics in Kaptai Lake, Bangladesh, using length-based indicators to support sustainable management strategies.

### **Key Objectives**
* Evaluate the current stock status of *G. giuris* in Kaptai Lake.
* Apply length-based assessment frameworks (e.g., LBSPR, LBB, or TropFishR).
* Provide actionable management recommendations for local freshwater fisheries.

---

## **Repository Contents**
* `/Data`: Cleaned length-frequency datasets.
* `/Scripts`: R code for mortality estimation, growth parameters, and status indicators.
* `/Results`: Summary tables and high-resolution figures.
